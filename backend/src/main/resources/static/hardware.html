Roadmap (planned, no dates committed)

Phase 1 · Now
Software prototype: detector, thermal twin, dashboard, red-team simulator, validated on simulated data.
Phase 2 · Pilot
Run on a real utility's existing meter data for one feeder and measure real accuracy.
Phase 3 · Hardware
Transformer-side sensing node (load, voltage, temperature) feeding the same engine.
Phase 4 · Scale
Multi-feeder rollout, utility integrations and field-team workflows.

Why hardware after software

The software proves the idea with data a utility already has. Hardware is only worth building once the detection logic works on real data, so the plan is software first, hardware when the pilot succeeds.

This page describes a plan. No hardware has been built or tested yet.
